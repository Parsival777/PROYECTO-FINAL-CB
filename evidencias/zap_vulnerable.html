🎯 Insecure Direct Object Reference (IDOR) - ALTA

Severidad: ALTA

Endpoint: /api/user/<id>, /profile?user_id=<id>

Descripción: La aplicación permite acceder a recursos de otros usuarios sin verificación de propietario.

Impacto: Exposición de historiales médicos, API keys, datos sensibles.

🛡️ Content-Security-Policy: FALTA

Severidad: MEDIA

Descripción: La aplicación no implementa CSP headers.

📏 X-Frame-Options: FALSO

Severidad: MEDIA

Descripción: Falta el header X-Frame-Options, riesgo de clickjacking.

Recomendación: Agregar X-Frame-Options: DENY o SAMEORIGIN

Severidad: BAJA
